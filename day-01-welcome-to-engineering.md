# Day 1 — Welcome to Engineering

## 1. What is an Engineer?

An engineer is a person who applies science, mathematics, technology, and practical knowledge to identify and solve real-world problems.

An engineer may solve problems using:
- Physical products and machines
- Electronic circuits
- Software
- Embedded systems
- Automation
- Artificial Intelligence (AI)

### Engineering Process

Problem → Understand → Plan → Design → Build → Test → Improve

Engineering is not only about creating something new. It is also about improving existing systems, making them safer, cheaper, faster, more efficient, and more reliable.

---

## 2. What is Engineering?

Engineering is the practical application of scientific and mathematical knowledge to design, build, test, and improve useful systems, products, and solutions.

Engineers work with both physical and digital systems.

Examples:
- Mobile phones
- Washing machines
- Cars
- Robots
- Drones
- Communication systems
- Computers
- Medical devices
- AI systems

---

## 3. Engineering Example — Washing Machine

A washing machine is an engineered system in which mechanical, electrical, electronic, sensing, and software/control systems work together.

### Input

The inputs of a washing machine can include:
- Clothes
- Detergent
- Water
- User-selected washing mode
- Electrical power

### Process

Inside the washing machine:
1. The user selects a washing program.
2. Water enters the machine.
3. Sensors provide information about the machine's condition.
4. The controller processes the information.
5. The motor rotates the drum.
6. The machine performs washing, rinsing, and spinning stages.
7. Water is removed during appropriate stages.

### Output

The main output is:
- Clean clothes

# 5. What is a Sensor?

A sensor is a device that detects or measures a physical quantity and provides information that a system can use.

### Simple definition

Sensor = Detects or Measures

A sensor can be thought of as a machine's "sense organ."

For example:
- Human eye → detects light
- Human ear → detects sound
- Temperature sensor → detects temperature
- Water-level sensor → detects water level

### Basic Sensor Flow

Physical quantity → Sensor → Electrical/Digital signal → Controller

---

# 7. Common Types of Sensors

## 7.1 Temperature Sensor

A temperature sensor measures temperature.

Examples:
- Thermistor
- RTD
- Thermocouple
- IC temperature sensor

Applications:
- Air conditioners
- Refrigerators
- Washing machines
- Industrial equipment

### Main idea

Temperature sensor → Measures temperature

---

## 7.2 Light Sensor

A light sensor detects or measures light intensity.

Examples:
- LDR
- Photodiode
- Phototransistor

### LDR

LDR stands for Light Dependent Resistor.

Its resistance changes according to the amount of light falling on it.

Applications:
- Automatic street lights
- Automatic brightness control
- Light detection systems

---

## 7.3 Proximity Sensor

A proximity sensor detects whether an object is nearby without necessarily touching it.

Examples:
- IR proximity sensor
- Inductive proximity sensor
- Capacitive proximity sensor

Application:
- Automatic dustbin
- Automatic doors
- Industrial object detection

### Example

Hand comes near a smart dustbin → Proximity sensor detects it → Controller receives information → Motor opens the lid

---

## 7.4 Distance Sensor

A distance sensor measures or estimates the distance between objects.

Examples:
- Ultrasonic sensor
- Infrared distance sensor
- Time-of-Flight sensor
- LiDAR

Applications:
- Robots
- Parking systems
- Obstacle detection
- Automatic doors

### Ultrasonic Sensor

An ultrasonic sensor sends a sound pulse and uses the reflected signal to estimate distance.

Sensor → Sound wave → Object → Reflected wave → Sensor

---

## 7.5 Pressure Sensor

A pressure sensor measures pressure.

Applications:
- Cars
- Aircraft
- Industrial systems
- Weather instruments
- Medical equipment

---

## 7.6 Force / Weight Sensor

A force sensor measures force.

A common example is a load cell.

Applications:
- Digital weighing machines
- Industrial weighing systems
- Load measurement

---

## 7.7 Motion Sensor

A motion sensor detects movement.

A common example is a PIR sensor.

PIR = Passive Infrared

Applications:
- Security systems
- Automatic lights
- Motion detection

### Important Difference

Motion sensor → Detects movement

Proximity sensor → Detects whether an object is nearby

In smartphones, accelerometers help detect device movement and orientation changes.

## 7.9 Gyroscope

A gyroscope measures angular or rotational motion.

Applications:
- Smartphones
- Drones
- Robots

Gyroscope → Measures angular/rotational motion

## 7.12 Humidity Sensor

## 7.14 Water-Level Sensor

A water-level sensor detects or measures how much water is present in a container or machine.

A flow sensor measures how a fluid is moving.

# 8. Analog and Digital Sensors

Sensors can also be classified according to the type of signal they provide.

## Analog Sensor

An analog sensor produces a continuously varying signal.

Example:

As temperature changes, the sensor's output can change continuously.

Temperature changes → Sensor output changes

The output may vary through many values such as:

0.5 V → 1.0 V → 1.5 V → 2.0 V

---

## Digital Sensor

A digital sensor provides information in digital form, often through discrete states or a digital communication interface.

Example:

Door:
- OPEN
- CLOSED

Many modern digital sensors contain electronic circuitry that processes the measurement before sending digital data to a controller.

---

# 9. Contact and Non-Contact Sensors

## Contact Sensor

A contact sensor requires physical contact with the object or mechanism being sensed.

Example:
- Mechanical switch

## Non-Contact Sensor

A non-contact sensor detects an object or physical condition without direct physical contact.

Examples:
- IR proximity sensor
- Ultrasonic sensor
- Some magnetic sensors

---

# 10. Active and Passive Sensors

Sensors can also be classified as active or passive, depending on how they operate.

### Passive Sensor

A passive sensor generally responds through a change in an electrical property and does not generate its own sensing energy.

Examples often include:
- Thermistor
- RTD
- LDR

### Active Sensor

An active sensing device generally requires external power or excitation to operate.

Examples can include:
- Ultrasonic sensing modules
- Many optical sensing systems

The exact classification can vary somewhat by textbook and engineering context.

---

# 11. What is a Controller?

A controller is the part of a system that receives information, processes it according to instructions, and decides what should happen.

### Simple definition

Controller = Decides

Examples:
- Microcontroller
- Microprocessor
- PLC

### Basic Flow

Sensor → Controller → Decision

---

# 12. What is an Actuator?

An actuator is a component that performs a physical action when it receives a command from the controller.

### Simple definition

Actuator = Acts

Examples:

Motor → Produces rotation

Valve → Opens or closes fluid flow

Relay → Switches electrical equipment

Buzzer → Produces sound

---

### General Flow

# 15. Safety Example

Suppose the washing machine door is open and the user presses Start.

The system should detect the unsafe condition and prevent the washing cycle from starting.

### Flow

Door sensor
↓
Controller detects door is open
↓
Controller prevents operation
↓
Machine does not start washing

This is an example of an engineering safety requirement.

# 16. Overload Detection

Suppose too many clothes are placed in the washing machine.

The system can use sensing and feedback related to motor behavior and other measurements to detect an abnormal load condition.

### Flow

Motor behavior
↓
Sensing / Feedback
↓
Controller
↓
Abnormal condition detected
↓
Warning / Adjustment / Stop

A system does not always need one separate sensor for every possible problem. Existing measurements can sometimes provide useful information about the system.

---

# 17. Feedback

Feedback is information returned to the controller about the current condition of the system.

### Basic Feedback System

Sensor → Controller → Actuator
↑                         ↓
└──────── Feedback ────────┘

### Washing Machine Example

1. Sensor checks the water level.
2. Controller receives the information.
3. Controller decides whether the water is sufficient.
4. Valve adds water if necessary.
5. Sensor checks the water level again.
6. Controller decides whether the machine can continue.

### Main Idea

Feedback allows the system to monitor its condition and make better decisions.

---

# 18. Example of Feedback

Suppose the controller says:

"Add more water."

The valve opens and water enters the machine.

The sensor then checks the water level again.

If the water is now sufficient:

Controller → Continue

If the water is still too low:

Controller → Continue adding water / take corrective action

This repeated checking is feedback.

---

# 19. Automation vs Artificial Intelligence

## Automation

Automation means a system follows programmed rules to perform tasks automatically.

Example:

IF water level is low
THEN add water.

The rule was programmed in advance.

---

## Artificial Intelligence

AI systems can use data and learned patterns to make predictions or decisions.

Example:

A smart washing system could analyze information such as:
- Load condition
- Motor behavior
- Temperature
- Washing time

It may use patterns in the data to predict possible imbalance or suggest an appropriate operation.

### Important Difference

Automation follows programmed rules.

AI can also learn patterns from data and use those patterns for predictions or decisions.

# 21. Smart Dustbin Example

A smart dustbin should open when a person's hand comes near it.

### Step 1

The system needs to detect:

Proximity / distance of the hand

### Step 2

A suitable sensor could be a proximity or distance sensor.

### Step 3

The sensor sends information to the controller.

### Step 4

The controller decides whether the hand is close enough.

### Step 5

The motor acts as an actuator and opens the lid.

### System

Hand comes near
↓
Proximity sensor
↓
Controller
↓
Decision
↓
Motor
↓
Lid opens

### Important condition

The controller should open the lid only when an object is detected within a specified distance.

For example:

Hand within set distance → Open lid

Hand farther away → Keep lid closed

# 24. Engineering Thinking

An engineer should not only ask:

"What does this device do?"

An engineer should also ask:

"What problem does it solve?"

"What information does it need?"

"How does it detect that information?"

"How does it make a decision?"

"How does it perform the action?"

"What happens if something goes wrong?"

"How can the system be made safer and more efficient?"
